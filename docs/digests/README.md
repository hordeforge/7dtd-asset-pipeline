# Digests

What we can learn from other projects: mods, pipelines, format writers, and
engine-research repos studied for techniques worth borrowing. A digest is
about *their* work, not ours — the decision to adopt or reject an idea lives
in an [ADR](../adrs/), and engine facts measured from any source land in
[research/research-provenance.md](../research/research-provenance.md) with the
tool that produced them.

## Conventions

- Name files after the subject: `<project-or-paper>.md`.
- Open with what was studied and why, close with what applies here and what
  deliberately does not.
- Cite versions and artifacts; a digest that cannot be re-verified is a wiki.
