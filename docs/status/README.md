# Status — the working state of this project

Two living pages, kept current rather than preserved: what this pipeline
cannot do yet, and what is waiting on somebody outside this session. Both are
working lists, not promises, and both are edited in place when the state
changes.

A decision that closes a gap becomes an [ADR](../adrs/); a gap large enough to
need a spec first becomes a [PRD](../prds/); a failure with evidence becomes a
[report](../reports/).

## Pages

- [improvements.md](improvements.md) — known capability gaps, what closes each,
  and the open-source tool that belongs to it.
- [blockers.md](blockers.md) — what needs a human, a licence, or a machine this
  session cannot reach, with the exact command and the confirmation for each.

## Conventions

- An entry names what is missing, why it matters, and what would close it —
  a gap with no closing move is a wish.
- Delete an entry when it is closed. History lives in git, not in a list a
  reader has to filter.
