# Getting started

The two entry pages, in the order to read them.

- [quickstart.md](quickstart.md) — the complete path from a host with nothing
  installed to a modlet shipping a validated bundle, with each step's cost.
- [setup.md](setup.md) — the same steps with their reasoning and alternatives:
  Python, the game path, the Unity revision, licensing, and the Windows module.

Read the quickstart first and run it; read setup when a step needs a different
answer than the default. Both are served from an installed package as
`shamway docs quickstart` and `shamway docs setup`.
