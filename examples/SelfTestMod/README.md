# Shamway self-test modlet

This repository's own acceptance fixture, and its worked example of a modlet
whose bundle is written **with no Unity editor**.

It is a real modlet, kept and committed — not scratch generated by a script.
That matters: after a failing run the built bundle is still here to inspect, a
change to the prop shows up as a diff of real artifacts, and anyone can deploy
it to a client by hand without reproducing a shell script's steps.

```bash
shamway script playtest-synthesized
```

That builds this modlet, deploys it, runs it through a live client, and asserts
the game loaded every object the writer emitted. `docs/validation.md` lists
what each assertion catches.

## What is here, and why each piece

| Path | Why |
|---|---|
| `assets-src/bundle/shamwaySelfTestProp.glb` | the mesh, asymmetric on all three axes (0.30 × 0.20 × 0.50 m) so a wrong orientation is visible, and carrying UV0 so a texture can map |
| `assets-src/bundle/shamwaySelfTestProp_albedo.png` | bound to the prefab's material by the `_albedo` convention; a large **R** and an up-arrow, so mirrored and upside-down each read wrong at a glance |
| `Config/blocks.xml` | one block, `Shape` + `Model` and nothing else — every extra property would be one more thing that could explain a failure |
| `UIAtlases/ItemIconAtlas/` | the icon, from `shamway generate mesh-icon`: a clay render, not the in-game look |
| `Resources/` + `tools/shamway/manifests/` | build outputs, committed together as one artifact, the way any consuming mod commits them |

The block sets **no `Class`**. A model block has none, and an invented one
aborts the whole XML file — see `docs/validation.md`.

## Rebuilding it

```bash
cd examples/SelfTestMod
shamway build
shamway validate
shamway check-icons
```

Commit the changed `Resources/` and manifest with whatever you changed in
`assets-src/`. They are one artifact.

## What a green run does and does not mean

It means the game **read** the bundle: the prefab resolved by stem, carried its
renderer, its mesh had the authored bounds, its material named the synthesized
shader. It does **not** mean the prop draws correctly — every assertion passes
on one rendered mirrored, face-down, or nowhere at all. That judgement is a
person's, and `shamway client capture` is where it gets filed.
